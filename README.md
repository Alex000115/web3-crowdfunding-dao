# Web3 Crowdfunding DAO

A decentralized crowdfunding platform built on Ethereum. This smart contract allows users to create campaigns, accept contributions in ETH, and withdraw funds only if the funding goal is met within the specified deadline.

## Features
- **Goal Enforcement**: Funds are locked until the goal is met.
- **Time Limits**: Campaigns have a strict deadline.
- **Refund Mechanism**: Contributors can withdraw their ETH if the campaign fails.
- **Owner Security**: Only the campaign creator can withdraw funds upon success.

## Prerequisites
- Node.js installed
- An Ethereum wallet (e.g., MetaMask)
- Testnet ETH (Sepolia/Goerli)
